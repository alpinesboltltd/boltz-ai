# Level-x Platform Overview

Level-x is an AI chat platform enabling you to embed intelligent assistants into your products. This documentation is organized to help you move from zero to production quickly:

1. Getting Started – fundamentals & quick start
2. Guides – task‑oriented walkthroughs (integration, customization, deployment)
3. Reference – stable, factual API & schema details
4. Architecture – deeper system & roadmap docs

If you're just starting, continue to the Quick Start.

## Core Capabilities

- Multi‑model AI orchestration (planned: Gemini, GPT‑4, Claude, Mistral, etc.)
- Embeddable website chat widget
- Knowledge ingestion (documents, web, Q&A) with vectorization
- Appearance & behavior customization
- API access for custom integrations

## Document Conventions

- JSON examples use double quotes and representative placeholder values
- Required fields are explicitly stated in tables or examples
- All endpoints are prefixed with `/api/` unless noted
