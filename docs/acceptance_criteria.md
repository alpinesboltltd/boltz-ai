# Acceptance Criteria - Level-x AI Frontend

## 1. Workspaces

- [ ] User can create a new workspace upon registration or from dashboard.
- [ ] User can switch between workspaces.
- [ ] User can invite members to a workspace (UI only for MVP if backend incomplete).
- [ ] Dashboard shows data relevant to the selected workspace.

## 2. Agents

- [ ] User can create a new agent and select "Virtual Assistant" as a template.
- [ ] "Virtual Assistant" comes with pre-defined system prompts and capabilities.
- [ ] User can customize the agent's name, appearance, and behavior.
- [ ] User can create a custom agent with a custom system prompt.

## 3. Training

- [ ] User can upload a PDF file for training.
- [ ] User can enter a Website URL for scraping/training.
- [ ] User can manually enter QnA pairs.
- [ ] User can enter raw text for training.

## 4. Integrations

- [ ] User can see a list of available integrations.
- [ ] User can configure the "Website Widget" integration.
- [ ] User can see "Zoom", "Teams", "Jitsi" in the integrations list (even if mock for MVP).

## 5. General

- [ ] UI is responsive and follows the "Premium" design aesthetic.
- [ ] Application builds and runs without errors.
